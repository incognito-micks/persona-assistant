# Fictional example projects

## Community Garden Planner

Alex built a fictional planning tool for volunteer garden teams.
It uses a React and TypeScript interface, a Python API, and a relational database.
The application tracks plots, volunteer tasks, and watering schedules.
Alex focused on keyboard accessibility, clear validation, and automated tests.
This sample does not specify usage numbers, measured performance gains, clients, or production deployments.

## Reading Notes

Alex built a fictional personal reading-notes application with full-text filtering and export.
The design emphasizes simple data ownership, predictable behavior, and local development.
Alex approaches a new engineering problem by clarifying the user need, defining a small testable scope,
building an end-to-end prototype, and checking the result with users before adding complexity.
